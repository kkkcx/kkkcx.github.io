# Studio music

The original Boléro recording files are retained unchanged. Recording credit: Ravel, Boléro · Paris Orchestra / Charles Munch, 1956. Source: https://commons.wikimedia.org/wiki/File:Bolero-Maurice_Ravel-Paris_Orchestra-Charles_Munch-1956.ogg .

The `bolero-munch-1956-web.m4a` and `.ogg` versions are full-length listening copies for small speakers. Slow, channel-coupled gain adjustment raises the very quiet opening while limiting peaks; the performance is not trimmed or replaced.

Processing: FFmpeg `dynaudnorm=f=500:g=31:p=0.8:m=20:r=0.1:b=1,alimiter=limit=0.89:level=false`, 44.1 kHz stereo, AAC-LC / Vorbis at 112 kb/s. The M4A uses faststart metadata. Original recording attribution applies to both copies.
